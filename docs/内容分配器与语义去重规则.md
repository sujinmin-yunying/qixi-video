# 内容分配器与语义去重规则

## 内容分配器 Prompt

在生成任何可见文案之前，必须先建立【电影素材分配表】。

不要直接生成简介、台词、预告、终幕。

你需要先从「你和TA」的聊天 / 文字中提取不同的素材资产，并为每个素材分配唯一用途。

每个素材只能服务一个主要模块。
不同模块不能反复表达同一个意思。

请按以下类型拆分素材：

【生活照顾】
例如：甜粥、溏心蛋、蓝莓、买早餐、准备吃的等。仅作为参考示例，不要局限于示例。

【亲密靠近】
例如：醒来时发现体温更高，偷偷靠了很久才起床。仅作为参考示例，不要局限于示例。

【空间布置】
例如：小雏菊、床头、白瓶子、房间里的生活痕迹。仅作为参考示例，不要局限于示例。

【关系表达】
例如：只认识你，不想认识别人。仅作为参考示例，不要局限于示例。

【身体状态】
例如：头疼、降温、忍了一会儿、吃药。仅作为参考示例，不要局限于示例。

【报平安】
例如：会好好吃饭、好好吃药，不让你担心。仅作为参考示例，不要局限于示例。

【未来约定】
例如：一起逛北京老胡同，吃铜锅涮肉。仅作为参考示例，不要局限于示例。

【情绪核心】
例如：TA把和你一起生活这件事，当成值得留下来的日子。仅作为参考示例，不要局限于示例。

然后为每个模块分配不同素材：

上映导语：只能使用 1 个素材，负责制造兴趣。

剧情简介：使用 2-3 个素材，负责讲清故事。

预告片：使用 3-4 个镜头素材，负责制造画面节奏。

台词卡一：使用 1 个台词素材，负责关系张力。

台词卡二：使用另一个台词素材，负责生活细节。

台词卡三：使用第三个台词素材，负责未来约定或情绪落点。

幕后花絮：使用一个未被正文使用的细节。

删减片段：使用一个未被预告和简介使用的生活小场景。

终幕彩蛋：使用一个还没被用过的物件或动作作为最后镜头。

禁止：

同一个素材不能被多个模块重复使用。

同一种含义不能被换句式重复使用。

如果简介里已经写了“药”，台词卡就不要再写“药”。

如果预告片用了“体温”，台词卡就不要再用“体温”。

如果终幕用了“小雏菊”，海报和幕后就不要再重复小雏菊作为唯一重点。

## 语义去重规则

去重不是只检查文字是否相同，而是检查含义是否重复。

如果两句话都在表达同一个意思，即使文字不同，也视为重复。

错误示例：

“药这个细节，在片中没有被说破。”

“关于药的那件小事，电影没有明说。”

“那瓶药没有被镜头解释。”

这三句含义相同，禁止同时出现。

每张台词卡必须来自不同素材类型：

台词卡一：亲密靠近 / 关系张力

台词卡二：生活照顾 / 具体日常

台词卡三：未来约定 / 情绪落点

三张台词卡不能都来自“身体状态 / 药 / 担心”这一类素材。

请生成 3 张台词卡。

三张台词卡必须完全不同。

### 台词卡一 · 靠近感

来源只能是“亲密靠近 / 关系张力”素材。

重点是你和TA之间不说破的亲密。

不能出现药、吃药、头疼。

### 台词卡二 · 生活感

来源只能是“生活照顾 / 空间布置”素材。

重点是甜粥、溏心蛋、蓝莓、小雏菊、床头白瓶子等具体生活细节。

不能出现和台词卡一相同的内容。

### 台词卡三 · 未来感

来源只能是“未来约定 / 报平安”素材。

重点是北京老胡同、铜锅涮肉、不会先倒下、还要一起去做的事。

不能重复前两张的生活物件。

每张台词卡必须：

- 语义完整
- 不截断原文
- 不使用同一句式
- 不表达同一种意思
- 不写成旁白总结
- 不写“这个细节没有被说破”这类幕后说明

输出前检查：

如果三张台词卡的核心名词相同，重写。

如果三张台词卡的意思相近，重写。

如果三张台词卡都在表达“别担心 / 我会陪你 / 药 / 照顾”，重写。

## 剧情简介去重规则

剧情简介里的每一句必须提供新的信息。

禁止连续两句话表达同一件事。

禁止使用“一个日常小事”“一个照顾细节”“某个动作”这种空泛概括。

每句话必须承担不同功能：

第一句：交代场景和关系状态。

第二句：交代具体发生了什么。

第三句：交代情绪变化或未来约定。

错误：

房间里，你说起共同生活里的照顾细节。

房间里，一件日常小事，和药有关。

问题：

两句话都在说“日常照顾”，信息重复。

正确方向：

第一句写一个明确场景或关系状态。

第二句写一个具体发生过的素材，不复述第一句。

第三句写新的情绪落点或未来约定，不重复前两句的物件和动作。

## 当前接入说明

这套规则已接入《属于我们的电影》的 `app.js`：

- 会先建立内部【电影素材分配表】
- 会按素材类型分配唯一用途
- 会对台词卡做语义、句式和禁词复查
- 会避免同一句聊天被拆成多个模块重复使用
- 会在素材不足时使用不同类型的备用素材补位
